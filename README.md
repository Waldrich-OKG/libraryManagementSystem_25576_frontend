# Library Management System (Frontend)

The frontend application built with React.js and TailwindCSS to provide a clean and responsive interface for the Library Management System backend.  
This project demonstrates component-based UI design, API integration, and modern styling practices.

# Features
- Responsive login and registration pages
- Dashboard for users and librarians
- Book catalog with search and filter
- Reservation and borrowing management UI
- Integration with backend REST APIs
- TailwindCSS utility classes for fast styling

# Tech Stack
- React.js (Vite)
- TailwindCSS
- Axios — backend communication
- React Router — navigation
- Node.js & npm — development environment
